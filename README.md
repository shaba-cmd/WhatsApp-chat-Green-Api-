# WhatsApp Chat — GREEN-API

Веб-чат для отправки и получения текстовых сообщений WhatsApp через GREEN-API. Интерфейс повторяет внешний вид WhatsApp Web.

Тестовое задание на должность «Фронтенд разработчик React».

Стек: React 19, TypeScript, Vite, axios. CSS Modules, без UI-библиотек. Бэкенда нет: запросы идут к GREEN-API прямо из браузера.

## Деплой

https://whats-app-chat-green-api.vercel.app/

## Запуск

Нужен Node.js 20+.

```bash
git clone https://github.com/shaba-cmd/WhatsApp-chat-Green-Api.git
cd WhatsApp-chat-Green-Api
npm install
npm run dev 
```

Открыть http://localhost:5173

Сборка: `npm run build`, результат в `dist/`.

## Возможности 

* Вход по данным инстанса GREEN-API (idInstance, apiTokenInstance, apiUrl) с проверкой, что инстанс авторизован.
* Создание чата по номеру телефона.
* Отправка текстовых сообщений.
* Получение ответов в реальном времени, без перезагрузки страницы.
* Если пишет номер, для которого чата ещё нет, чат создаётся автоматически.

## Подготовка инстанса GREEN-API

1. Зарегистрироваться в [личном кабинете](https://console.green-api.com) и создать инстанс (тариф Developer бесплатный).
2. Привязать WhatsApp: отсканировать QR-код в кабинете (WhatsApp → Связанные устройства).
3. В настройках инстанса: **поле URL вебхука оставить пустым**, включить «Получать уведомления о входящих сообщениях».
4. Скопировать `idInstance` и `apiTokenInstance` и ввести их на экране входа.

Важно про apiUrl. У каждого инстанса свой хост, например https://7107.api.greenapi.com. Он указан в кабинете рядом с idInstance. С неверным хостом запросы вернут ошибку, поэтому на экране входа его нужно ввести вместе с остальными данными.

## Как это работает

- Отправка: метод [SendMessage](https://green-api.com/docs/api/sending/SendMessage/).
- Получение: [HTTP API](https://green-api.com/docs/api/receiving/technology-http-api/) — цикл
  `ReceiveNotification` → обработка → `DeleteNotification`.


## Как пользоваться

1. Введите apiUrl, idInstance и apiTokenInstance и нажмите «Войти».
2. Введите номер получателя в международном формате без + (например, 79991234567) и нажмите «Создать».
3. Напишите сообщение и отправьте его кнопкой или клавишей Enter.
4. Ответ получателя появится в чате автоматически.

Входящие нужно проверять с другого аккаунта WhatsApp: сообщение самому себе не приходит как входящее.

## Ограничения

По условиям задания интерфейс минимальный:

* только текстовые сообщения и личные чаты, без медиа и групп;
* история переписки не загружается, чаты и сообщения хранятся до перезагрузки страницы;
* данные входа хранятся в sessionStorage вкладки и удаляются при выходе или закрытии вкладки;
* вёрстка рассчитана на экраны от 1024 px.
